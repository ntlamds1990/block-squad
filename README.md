# Block Squad

Blocky fantasy squad tactics for phones. Lead Sir Bram, Wren, Ember and Digby against the Goblin Horde.

**Play:** https://ntlamds1990.github.io/block-squad/ — open in Chrome on Android and tap **Add to Home screen**. No login needed, and it works offline after the first visit.

This is the Milestone 0 prototype: one battle in the meadow village against the CPU, on Easy or Normal.

Built with [Three.js](https://threejs.org) r128 (MIT, vendored in `vendor/`).
